# ACTIVEVIEW v9.1: Perception-Aware Active View Selection

> **Scientific Benchmark & Final Specification**  
> *"The robot receives imperfect human observations generated by a perception module. The goal is to actively select viewpoints that improve future human observation quality."*  
> *(机器人只能获得不完整人体观测，本文研究如何主动选择视角提升后续感知质量。)*

---

## 1. 核心科研问题与信息边界 (Scientific Scope & Information Boundary)

在真实人机共存环境中，由于**环境遮挡、人体自遮挡与视角限制**，机器人单次获取的人体观测始终是不完整的，无法直接获得 Ground-Truth 人体状态或动作标签。

### 核心科学问题 (Core Research Problem):
机器人如何根据**当前不完整的观测感知质量 $O_t$**（视觉估计关节坐标、关节置信度与身体部位可见性），主动规划下一个观察视角 $v$，以**最大化未来的信息增益（Information Gain）与状态感知质量提升**：
$$v^* = \arg\max_{v \in \mathcal{V}_{\text{feasible}}} \hat{G}(v \mid O_t)$$

### 严格信息边界 (Strict Information Boundaries):
- ❌ **No GT Human State / No SMPL-X GT in Forward Pass**: 模型输入严格来自估计感知状态 $O_t$；
- ❌ **No Action Label in Model Forward**: 动作标签严禁输入模型，仅用于离线分组与统计；
- ❌ **No Future Observation Leakage**: 候选视点描述子仅含视距与角度等空间几何，严禁提前渲染偷看未来真实观测；
- ❌ **No Temporal / RL / SLAM / Global Navigation**: 聚焦于单步局部主动视角信息增益规划。

## 2. 感知状态与网络架构 (Perception State & Architecture)

### 当前观测状态特征向量 (Observation State $O_t$, 71d):
1. **16 关节点估计 3D 坐标** ($p_{\text{est}} = p_{\text{gt}} + \epsilon$，相对估计骨盆归一化坐标)：$16 \times 3 = 48\text{d}$；
2. **16 关节点估计置信度** ($c_i \in [0.0, 1.0]$)：$16\text{d}$；
3. **7 大身体关键解剖部位可见性置信度** (`head`, `torso`, `pelvis`, `left_hand`, `right_hand`, `left_leg`, `right_leg`)：$7\text{d}$。

### 候选视角几何描述子 (View Descriptor $v$, 13d):
包含视点空间距离、相对偏角 $\sin/\cos$、相对高度与视锥几何参数。

### 神经网络架构:
```text
Observation State O_t (71d) ────► [ObservationEncoder]   (32d) ┐
                                                                 ├─► [Fusion MLP] ──► Predicted Info Gain G_hat(v|O_t) ∈ [0, 1]
Candidate View Descriptor v (13d) ──► [ViewFeatureEncoder] (32d) ┘   (64d -> 64d -> 32d -> 1d)
```

## 3. 训练目标与信息增益标签 (Information Gain Target)

真实目标由视角移动后的观测感知质量增量决定：
$$\text{Gain}(v) = \text{ObservationQuality}_{\text{after}}(v) - \text{ObservationQuality}_{\text{before}}(v_t)$$
其中：
$$\text{ObservationQuality} = 0.40 \cdot \bar{c}_{\text{joints}} + 0.35 \cdot \bar{c}_{\text{parts}} + 0.25 \cdot \text{Completeness} - 0.10 \cdot \text{dist\_penalty}$$
采用 **Pairwise Ranking Loss + Regression Loss** 进行排序训练，使模型专注于发现信息增益最大的最佳视角。
