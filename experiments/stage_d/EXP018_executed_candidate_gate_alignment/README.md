# EXP018 — Executed-Candidate Gate Alignment Audit

**Status: COMPLETED; Val-only analysis, no deployable policy accepted.**

EXP018 audits whether the second-step gate target should ask whether *any*
candidate is useful or whether the candidate frozen EXP014 would actually
execute is useful. It is an analysis-only counterfactual: the Stage C-v0
first action and p1 proposal are frozen, and the corrected EXP014 p2/p3
ranking is reused exactly (`predicted utility → geodesic → viewpoint ID`).

For each v0-Move episode:

```text
y_any  = max(true U2(p2), true U2(p3)) > 0
c_hat  = frozen learned EXP014 candidate
y_exec = true U2(c_hat) > 0
```

True U2 is used only for offline gate analysis. It never selects a candidate
for the learned ranking. v0-Stay episodes remain Stay at s0.

The run reads frozen Stage B/Stage C-v0/EXP014/EXP017 Val artifacts only. It
does not train, regenerate perception, render Habitat, or access Test.

## Reproduction

```bash
bash experiments/stage_d/EXP018_executed_candidate_gate_alignment/run.sh
```

The complete JSON is written under `ACTIVEVIEW_DATA_ROOT/experiments/stage_d/`
and the compact result committed here is generated by the same command.
