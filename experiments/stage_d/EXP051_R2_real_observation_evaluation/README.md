# EXP051-R2 — Real-Observation H1/H2 Evaluation

Val-only paired evaluation of the frozen EXP051-R1 policy. H1 and H2 use the
same 9,742 v0-Move contexts and differ only in the maximum number of moves.
Terminal recognition and fusion use archived real-view frozen ST-GCN log
probabilities; imagined WM-E probabilities are used only for action selection
and fidelity diagnostics.

No model was trained, no perception was regenerated, and Test is locked.
