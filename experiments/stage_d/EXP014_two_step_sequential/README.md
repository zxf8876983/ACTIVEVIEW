# EXP014 — Two-Step Sequential Policy

**Status: COMPLETED (Val-only; no Test evaluation).**

## Scientific question

Can one real intermediate observation resolve enough uncertainty to improve
final recognition beyond the one-shot Stage C-v0 plateau?

## Single change

Add one second-step `SequentialObservationRanker` after the frozen Stage C-v0
Top-1 proposal. The first Move/Stay decision, Top-3 proposal ordering, split,
ST-GCN checkpoint, Stage A/B and Stage C-v0 artifacts remain frozen.

## Decision protocol

If frozen v0 predicts Stay (`max utility <= 0`), EXP014 also stays at `s0`.
Otherwise it visits `p1`, computes the 275-D frozen ST-GCN state from the
already cached `p1` skeleton, and chooses Stay/p2/p3 from the second-step
predictions. `p2/p3` future perception is hidden until selected.

## Inputs and target

The model receives `s0` 275-D, observed `s1` 275-D, their 19-D semantic delta,
and two 11-D geometries recomputed from `s1`. The supervision target is
`U2(c|s1) = logp_true(c) - logp_true(s1)` and is used only as training/offline
evaluation target. No GT label, `logp_true`, correctness, SafeOracle or future
unvisited perception enters policy input.

## Training and selection

Train samples are generated by the frozen v0 policy and sampled with 16
second-step Episodes per eligible record per epoch. AdamW, seed 42, batch 128,
100 epochs, patience 10, learning rate 1e-3, weight decay 1e-4, gradient clip
1.0 and the frozen Stage C-v0 SmoothL1 + stay-inclusive listwise objective
(`lambda_reg=1`, `lambda_rank=1`, `tau=0.5`, `lambda_gap=0`) are fixed.
Checkpoint selection uses complete Val trajectory Macro-F1, not candidate-only
accuracy. Proposed success thresholds are Val Accuracy ≥68% and ≥10% mean
regret improvement for strong success; these are criteria for later review,
not automatic evaluator output.

## Runtime order

`run.sh` will (when explicitly authorized) generate/load frozen v0 Train/Val
proposal predictions, build the Stage D cache, train, and run Val trajectory
evaluation. It does not expose a Test option.

CUDA (`cuda:0`, RTX 4090). The selected checkpoint was epoch 24. Compact

decision is therefore **INCONCLUSIVE**, pending human scientific review.
