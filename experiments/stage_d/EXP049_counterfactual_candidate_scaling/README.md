# EXP049 — Counterfactual Candidate-Set Scaling

Val-only inference audit using the frozen EXP046 imagined-recognition cache.
Candidate sets are deterministic legal prefixes (`M=2,4,8,16,ALL_LEGAL`),
ordered by geodesic distance, absolute radial-azimuth difference, then
viewpoint ID. No model or perception training is performed.

`result.json` is generated by `activeview.scripts.run_stage_d_exp049_051`.
Test access is prohibited; all reported policy rows use frozen Stage C-v0
first-step decisions.
