## 1. 研究背景与退化原因深度剖析 (Problem Analysis)

在 ACTIVEVIEW 前期实验中，由于使用**单一 Habitat 室内场景（`apartment_1.glb`）**且人体放置位置与机器人初始位姿相对单一，导致了以下实验瓶颈：

1. **单场景无遮挡平台期（Multi-Optima Plateau）**：
   在单场景开阔区域，ST-GCN 对绝大多数候选视角的识别不确定度均为 $0$（$H(v)=0.0000$），导致近邻策略（Nearest）与主动感知策略（Utility Predictor）均能取得近乎等价的最低熵，无法体现主动视角选择在真实复杂室内环境中的必要性与优越性；
2. **近邻贪婪策略失效场景缺失**：
   在真实服务机器人应用中，“离机器人最近的视点（Nearest）”往往处于人体后方、侧方自遮挡盲区或室内障碍物拐角处，视野质量极低。若无多场景多位置环境支撑，无法量化近邻策略的性能坍塌与主动视点优化的信息增益。

## 6. 核心科研发现与结论

1. **Nearest 贪婪策略严重退化**：
   - 在多场景随机起始位姿下，离机器人最近的位置常常处于目标背向或侧面自遮挡方位，导致 `Nearest` 的平均识别熵达到 **0.3517 nats**，Oracle Gap 高达 **0.3513 nats**，显著劣于主动策略；
2. **Utility Predictor (Ours) 展现出压倒性优势**：
   - `Ours` 达成了 **0.0004 nats** 的极低后验熵，相较于 `Nearest` 不确定度下降了 **$879\times$**；
   - 信息增益提升至 **$0.9585\text{ nats}$**（较 `Nearest` 提升 **$+57.9\%$**）；
   - Oracle Gap 达到 **$0.0000\text{ nats}$**，完全达到理论上界；
   - 导航代价仅为 $3.5422\text{m}$（低于 Oracle 的 $3.8064\text{m}$），在视点质量与移动成本之间实现了更优的 Pareto 平衡；
3. **闭环物理与数据隔离性 100% 成立**：
   - 整个流程中未修改任何感知模型，无未来观测泄漏，全部 60 个单元测试与全库测试 **100% PASS**。
