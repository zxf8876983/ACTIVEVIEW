## 2. 16 类全量非位移动作数据集体系 (16-Class Action Space)

### 2.1 动作类别定义与分类学构建
全面排除大范围平移与奔跑动作（`walk`, `walk forward`, `run`, `jog`, `crawl`），精选并构建了 16 种高频家庭非位移动作：

| 动作类别 (Category) | 动作类型 / 生物力学特征 | 关节点主要动态与时空特征 |
|---|---|---|
| 1. `standing` | 静态直立 | 站立姿态，伴随躯干微小呼吸摆动 |
| 2. `sitting` | 静态坐姿 | 双膝 90° 弯曲、骨盆低重心维持 |
| 3. `sit_down` | 坐下动态转换 | 骨盆自 0.95m 平滑下降至 0.50m，双膝前移弯曲 |
| 4. `stand_up` | 起立动态转换 | 骨盆自 0.50m 向上推起至 0.95m，双膝伸直复原 |
| 5. `bending` | 躯干弯曲 | 脊柱向前大角度前倾 70°，头部前伸下沉 |
| 6. `reaching` | 单侧伸手伸展 | 单侧手臂向前上方显著探出探物 |
| 7. `picking_up` | 俯身捡拾物品 | 深度前倾弯腰与屈膝复合，双手探至地面高度 (0.15m) |
| 8. `squatting` | 深度下蹲 | 骨盆降至极低位置 (0.40m)，双膝深度折叠，双臂前伸平衡 |
| 9. `jumping` | 原地起跳 | 身体重心瞬间向上腾空 (+0.35m)，双膝压缩后迅速蹬直 |
| 10. `turning` | 原地转身 | 骨盆与双肩绕垂直轴执行 180° 偏航转体 |
| 11. `stretching` | 身体舒展拉伸 | 双臂向两侧及上方大幅伸展舒张 |
| 12. `waving` | 招手挥手 | 右前臂与手腕在肩部高度执行高频往复横向摆动 |
| 13. `dancing` | 舞蹈律动 | 躯干与四肢呈现非对称节奏性交叉协调摆动 |
| 14. `kicking` | 单腿强力前踢 | 单侧下肢向前上方强力踢出，单腿支撑重心平衡 |
| 15. `fall_stumble` | 踉跄失稳跌倒 | 身体重心失稳前冲，躯干自竖直快速跌落至水平贴地 |
| 16. `placing` | 弯身放置物品 | 躯干微倾，双手平稳将物品放置于桌面/低矮台面 |

- **数据集规格**：
  - 训练集：**3,200 条样本**（每类 200 条）；
  - 测试集：**800 条样本**（每类 50 条）；
  - 骨架数据维度：$(C=3, T=30, V=33, M=1)$，严格无缺失无 NaN。

## 6. 自查与问题诊断：为什么当前准确率全为 100% 及后续整改路线

在本次 v11.4 闭环评测中，针对移动后准确率（`Acc_after`）在所有策略下均显示为 $100\%$ 的现象，团队进行了深度的科研自查与代码级归因（详见专项自查文档：[`V11.4_SELF_INSPECTION_AND_ISSUE_DIAGNOSIS.md`](file:///home/zxf/WorkSpace/code/code/ActiveView/V11.4_SELF_INSPECTION_AND_ISSUE_DIAGNOSIS.md)）：

### 6.1 准确率全员 100% 的根本原因诊断
1. **测试评估阶段真值骨架直通（Ground-Truth 3D Bypass）**：
   - 当前评测代码直接读取了 AMASS 的真值 3D 骨架坐标进行刚体旋转，**跳过了在 Habitat 场景中渲染真实 RGB-D 图像并运行 2D/3D Pose 估计器提取骨架的真实感知步骤**；
2. **温度缩放无法改变 $\text{argmax}$ 判决**：
   - 物理遮挡率作为温度系数 $T$ 压扁了概率分布（提高了熵并降低了置信度），但由于 $\text{argmax}_i(\text{logits}_i/T) \equiv \text{argmax}_i(\text{logits}_i)$，只要输入的 3D 骨架没有发生真实的关节点缺失与噪声污染，分类器在 $\text{argmax}$ 下永远输出正确类别；
3. **缺少真实家具网格阻断引起的关节丢失（Joint Occlusion Missingness）**：
   - 在真实物理环境中，停留在沙发后的机器人只能拍到上半身，Pose 检测器无法提取下半身关键点，输出残缺骨架会导致 ST-GCN 准确率暴跌至 $30\% \sim 55\%$；而当前代码中输入的骨架 100% 完整，破坏了物理遮挡的真实性。

---

### 6.2 训练与测试感知边界严格规范与整改方案
1. **彻底废除任何 Ground-Truth 3D 骨架直通**：
   - 严禁在感知与决策阶段读取或使用任何 AMASS 3D 真值坐标；
2. **训练阶段（Clean Perception）**：
   - 纯净虚拟摄影棚无遮挡背景渲染仿真人体 $\to$ Pose 估计器提取估计骨架 $\to$ 训练 ST-GCN；
3. **测试阶段（Habitat Environment Perception）**：
   - 将人体放置在 Habitat 住宅网格（沙发/餐桌/门后） $\to$ 机器人视点渲染真实 RGB-D $\to$ 由 Pose 估计器提取受家具遮挡影响的残缺/估计骨架 $\to$ 送入 ST-GCN 分类；
   - 真实呈现 `Nearest` 停留在遮挡盲区导致的准确率骤降，以及 `Ours` 绕障到达最优视点维持高准确率的真实科学对比。
