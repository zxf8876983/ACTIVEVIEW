## 3. 三阶段 Habitat 过滤日志与统计 (Filtering Statistics)

在标准室内环境（包含人体目标、机器人初始位姿与物理障碍物）下运行过滤器输出的结构化统计：

```text
=========================================================
Candidate Generation:
  Generated candidates: 32

Filtering:
  Navigable: 29 / 32
  Reachable: 29 / 29
  Visible:   28 / 29

Final feasible viewpoints: 28 / 32
=========================================================
```

### 过滤机制解析：
1. **NavMesh 可行走性过滤（Stage 1）**：落入家具或墙体内部的 3 个候选点被精准剔除（`is_navigable=False`）；
2. **测地线路径可达性过滤（Stage 2）**：机器人计算到候选视点的最短连通路径与移动距离 `navigation_cost`；
3. **视线通视性检测（Stage 3）**：Raycast 发现 1 个位于隔断屏风后的视点存在严重视线遮挡，被剔除（`is_visible=False`）；
4. **最终输出**：输出 28 个具备高质量观测潜力的有效候选视点。
