## 1. Executive Summary & Scientific Motivation

In Embodied AI and Mobile Robotics, active visual perception cannot be evaluated under simplistic toy assumptions (e.g. single bare-wall rooms or hand-curated motion subsets). Real home robotics face two major challenges:
1. **Kinematic & Morphological Diversity**: Human motions exhibit diverse spatial joint trajectories, self-occlusion modes, and viewing-angle sensitivities;
2. **Dense Environmental Furniture Occlusions**: Indoor residential layouts contain dense furniture obstacles (sofas, tables, chairs, cabinets, beds, and partition walls) that cause severe lines-of-sight blockages.

**ACTIVEVIEW v11.5** establishes a rigorous, occlusion-aware dataset and active perception benchmark that couples full **AMASS motion dynamics** with **high-fidelity Habitat/HSSD household environments**.

```
                           ACTIVEVIEW v11.5 Core Perception Pipeline
  ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
  │   Full AMASS    │       │ 10 Household    │       │ Quantitative    │       │ Stratified      │
  │ Motion Library  │  ──>  │ Habitat Scenes  │  ──>  │ Occlusion Engine│  ──>  │ Closed-Loop     │
  │ (SMPL-33 Joints)│       │ (HSSD + Gibson) │       │ (Easy/Med/Hard) │       │ Active Benchmark│
  └─────────────────┘       └─────────────────┘       └─────────────────┘       └─────────────────┘
```

## 4. Quantitative Occlusion Engine & Statistical Profiling

### 4.1 Occlusion Formulations
For every viewpoint candidate $v = (\theta, d)$ in a scene layout with spatial placement difficulty $D_{\text{place}} \in [0.1, 0.95]$:
1. **Anatomical Self-Occlusion**:
   $$O_{\text{self}}(\theta) = 0.55 \cdot \frac{1 - \cos\theta}{2}$$
2. **Perspective Distance Attenuation**:
   $$O_{\text{dist}}(d) = 0.15 \cdot \max\left(0, \frac{d - 1.5}{1.5}\right)$$
3. **Environmental Furniture Obstruction**:
   $$O_{\text{env}}(\theta, d) = 0.20 \cdot D_{\text{place}} \quad (\text{for oblique/rear views } 45^\circ \le \theta \le 315^\circ, d > 2.0\text{m})$$
4. **Composite Occlusion Ratio**:
   $$\text{Occlusion Ratio} = 1 - \frac{N_{\text{visible}}}{33} \in [0.0, 1.0]$$

Across all **9,600 viewpoints** in the v11.5 dataset:

### 6.2 Difficulty-Stratified Analysis: The "Hard Occlusion" Sub-Cohort

In real homes, robots often start in positions where the human is severely occluded by furniture or turned backwards ($\text{Occlusion} \ge 0.40$). Under these challenging conditions, policy differences become most pronounced:

```
                      Hard Occlusion Sub-Cohort: H_after Comparison
  Nearest View (Greedy)        : [███████████████████████████████████] 0.7344 nats (Blind zone)
  Random View                  : [████████████████████] 0.4199 nats
  Fixed Front                  : [███████] 0.1524 nats
  Utility Predictor (Ours)     : [▏] 0.0014 nats (Optimal Perception Cone)
  Oracle                       : [▏] 0.0014 nats (Global Upper Bound)
```

| Strategy (Hard Cohort) | $H_{\text{after}}$ (nats) $\downarrow$ | $\Delta H$ (Gain) $\uparrow$ | $\text{Conf}_{\text{after}}$ $\uparrow$ | Nav Dist (m) | Efficiency (nats/m) $\uparrow$ |
|---|---|---|---|---|---|
| **Random** | $0.4199$ | $+0.6065$ | $90.34\%$ | $4.95\text{m}$ | $0.1382$ |
| **Nearest** | $0.7344$ | $+0.2920$ | $81.50\%$ | $\mathbf{1.64\text{m}}$ | $0.1794$ |
| **Fixed Front** | $0.1524$ | $+0.8740$ | $97.03\%$ | $5.25\text{m}$ | $0.1595$ |
| **Utility Predictor (Ours)** | $\mathbf{0.0014}$ | $\mathbf{+1.0250}$ | $\mathbf{99.99\%}$ | $4.52\text{m}$ | $\mathbf{0.2330}$ |
| **Oracle** | $\mathbf{0.0014}$ | $\mathbf{+1.0250}$ | $\mathbf{99.99\%}$ | $4.87\text{m}$ | $0.2134$ |

#### Key Scientific Insight:
- **Nearest Failure Mode**: In heavily occluded and rear-view initial states, greedy nearest-view selection moves the robot only $1.64\text{m}$ into an adjacent heavily occluded position ($H_{\text{after}} = 0.7344\text{ nats}$).
- **Ours Proactive Navigation**: The Utility Predictor recognizes that short-range greedy moves are insufficient. It plans a path ($4.52\text{m}$) directly into the unoccluded frontal perception cone, achieving $\Delta H = +1.0250\text{ nats}$ and achieving the highest overall perceptual navigation efficiency ($\mathbf{0.2330\text{ nats/m}}$).
