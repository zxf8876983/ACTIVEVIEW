# ACTIVEVIEW v10.0 Research Development Document

## Version

**ACTIVEVIEW v10.0**

**Title:** RGB-D Driven Task-aware Active View Selection for Human Action Recognition

**核心目标：** 从 v9.1 的 Perception-aware Active View Selection 进一步发展到 Task-driven Active Perception，使机器人主动选择能够最大化动作识别性能的观察视角。

---

# 1. Research Motivation

机器人在家庭养老、人机协作和智能监护场景中需要理解人体行为。然而室内环境存在：

- 家具遮挡
- 人体自遮挡
- 视角限制
- 姿态估计缺失

固定摄像头或随机视角无法保证动作识别可靠性。

v10.0研究问题：

> 当机器人当前观察不足时，是否可以主动选择新的观察视角，提高人体动作识别准确率？

---

# 2. Research Boundary

## 2.1 本版本研究内容

研究核心：

**Active View Selection Policy**

即：如何根据当前视觉状态选择下一观察视角。

---

## 2.2 不研究内容

### 不研究导航

假设机器人已经位于人体附近，可到达候选视点。

### 不研究SLAM

Habitat提供环境地图。

### 不研究姿态估计算法

采用现有开源模型。

### 不研究动作识别网络结构

采用ST-GCN作为基础识别器。

---

# 3. Overall Pipeline

```
Habitat Scene
    |
    Human Motion
    |
    RGB-D Observation
    |
    2D Pose Estimator
    |
    Depth Back Projection
    |
    3D Skeleton
    |
    ST-GCN Action Recognition
    |
    Action Probability
    |
    Active View Selector
    |
    Next Best View
    |
    Improved Action Recognition
```

# 4. Sensor Assumption

机器人传感器：

- RGB camera
- Depth camera

Habitat用于提供：

- RGB image
- Depth image
- Camera pose
- Scene geometry

GT信息只能用于：

1. 数据生成
2. Oracle upper bound
3. 离线评价

禁止进入模型forward。

---

# 5. Human Pose Pipeline

## 5.1 Pose Estimator

采用现有模型：

推荐：

- RTMPose
- MediaPipe Pose

不训练新的姿态估计器。

---

## 5.2 3D Pose Reconstruction

流程：

RGB -> 2D keypoints

Depth -> Camera projection

2D keypoints + depth -> 3D skeleton

公式：

X=(u-cx)D/fx

Y=(v-cy)D/fy

Z=D

---

# 6. Skeleton Processing

输入：

T x J x 3

其中：

T：时间帧数

J：人体关节点数量

---

## Normalization

必须：

### Root normalization

以pelvis为中心：

p'=p-p_root

### Scale normalization

根据人体高度归一化。

---

## 不进行

禁止camera-facing rotation normalization。

原因：

视角变化属于ACTIVEVIEW研究变量。

---

# 7. Action Recognition Module

模型：

ST-GCN

输入：

3D Skeleton Sequence

输出：

Action Probability

例如：

falling:0.85
walking:0.10
sitting:0.05

# 12. Active View Selection

## 输入

Current observation:

- estimated 3D pose
- joint confidence
- action probability
- current camera information

Candidate view:

- distance
- relative angle
- height
- geometry descriptor

---

## 输出

Candidate view score。

目标：

最大化动作识别收益。

---

# 13. Optimization Objective

定义：

Action Gain:

Gain(v)=Confidence_after(v)-Confidence_before

或者：

Gain(v)=Entropy_before-Entropy_after

目标：

选择最大Gain视角。
